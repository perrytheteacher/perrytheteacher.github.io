Cíl

Umím pojmenovat sůl kyslíkaté kyseliny podle vzorce a napsat vzorec podle názvu.

Poznám, že to umím, když…

  • z názvu kyseliny odvodím anion a jeho oxidační číslo,
  • dopočítám oxidační číslo kationtu ze vzorce,
  • sestavím vzorec křížovým pravidlem se závorkami a krácením,
  • pojmenuji amonnou sůl, hydrogensůl i hydrát.

Všechny jsou soli kyslíkatých kyselin (oxosoli): kation kovu + anion kyseliny.

Otázka na dnešek: jak ze jména síran železitý poznám, že vzorec je Fe2(SO4)3?

  • Myslím – dvojice – sdílím (1 + 1 min). Očekávané odpovědi: „všechny mají kyslík“, „jsou to soli“, „mají kov“. Doveďte k: kation kovu + anion kyslíkaté kyseliny.
  • Sádra pro zlomeniny, modrá skalice na postřik vinné révy, hypermangan na dezinfekci – krátká souvislost s běžným životem.

Co je oxosůl

V kyselině nahradíme vodíkové kationty kationty kovu:

H2SO4 → odtrhneme 2 H+ → SO4−II → + 2 Na+I → Na2SO4
Vzorec: kation vlevo, anion vpravo
Název: anion (podstatné jm.) + kation (přídavné jm.) → síran sodný
Oxidační číslo aniontu = − počet odtržených H
součet oxidačních čísel ve sloučenině = 0

Podpůrná otázka: Kolik vodíků odtrhneme z H3PO4 a jaké oxidační číslo bude mít PO4? (3, −III).

Odborně: „oxidační číslo aniontu“ je školní zkratka pro náboj iontu (2−). Stojí za to to jednou říct, aby žáci nezaměňovali −II aniontu a +VI síry.

Od vzorce k názvu

  1. Rozděl vzorec: kation vepředu / anion zbytek
  2. Urči anion: doplň vodíky na kyselinu → název aniontu a oxidační číslo
  3. Urči kation: pevné ox. číslo přečti, jinak dopočítej (součet = 0)
  4. Sestav název a ověř křížovým pravidlem

Postupně odkrývejte. Žáci si kroky zapíší jako algoritmus – v úloze Najdi chybu budou určovat, ve kterém kroku chyba vznikla.

Příklad: Fe2(SO4)3

  1. Fe2 / (SO4)3
  2. SO4 ← H2SO4, kyselina sírová → síran, −II
  3. 2 · x + 3 · (−II) = 0 → x = +III → železitý
  4. síran železitý  kontrola: Fe+III a SO4−II → Fe2(SO4)3 ✓

Před krokem 3 se zeptejte: Můžeme oxidační číslo železa vyčíst z indexu? Tady náhodou ano (index aniontu 3), ale obecně ne – viz další příklad.

Příklad: CuSO4 – past na index

  1. anion SO4 → síran, −II
  2. x + (−II) = 0 → x = +II
  3. síran měďnatý
Pozor: index 1 u Cu neznamená +I! Indexy se zkrátily: Cu2(SO4)2 → CuSO4.
Oxidační číslo vždy dopočítej.

Typická chyba: „síran měďný“, protože u mědi „není číslo“. Ukažte nezkrácený zápis Cu2(SO4)2.

Od názvu ke vzorci

  1. Kyselina z názvu aniontu: dusičnan → HNO3
  2. Anion: odtrhni všechny H → NO3, −I
  3. Kation z koncovky: vápenatý → Ca+II
  4. Křížem: ox. číslo jedné části = index druhé → Ca(NO3)2
  5. Kontrola: +II + 2 · (−I) = 0 ✓

Zdůrazněte: index se přepisuje bez znaménka a jen jako počet. Indexy uvnitř aniontu (O3) se nemění.
